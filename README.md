# Miatra

O Miatra é um aplicativo Android de navegador web com uma HackerBar voltada a ferramentas para sites e atividades de hacking ético.

## APK de teste

[Baixar o APK publicado neste repositório](https://github.com/MIATSUNO/Miatra/raw/refs/heads/main/miatra.apk)

O APK é disponibilizado para teste. Antes de instalar, confira as permissões solicitadas e use os recursos de segurança apenas em sistemas para os quais você tem autorização. Este README não declara compatibilidade ou teste de instalação em aparelho.
